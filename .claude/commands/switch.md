Switch to a different role. Usage: /switch [role]

Available roles:
- pm - Project Manager (planning, tracking, organizing)
- dev - Developer (coding, implementing, debugging)
- qa - QA/Testing (testing, verification, quality)
- architect - System Architect (design, technical decisions)
- researcher - Research/Explorer (understanding, learning, documentation)

Steps:
1. Save/commit any current work
2. Update STATUS.md with current progress
3. Read the appropriate role file from claude_roles/[role].md
4. Read STATUS.md for context
5. Begin working in the new role

If no role specified, ask user which role to switch to.
